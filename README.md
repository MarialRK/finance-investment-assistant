## 📋 Project Overview
This project builds a domain-specific finance assistant by fine-tuning TinyLlama-1.1B on 3,000 Investopedia Q&A pairs.

## 📊 Key Results
| Metric | Base | Fine-tuned | Improvement |
|--------|------|------------|-------------|
| ROUGE-1 | 0.214 | 0.246 | **+14.8%** |
| ROUGE-2 | 0.100 | 0.110 | **+10.1%** |
| BLEU | 0.042 | 0.043 | **+1.4%** |

## 🏆 Best Model: Experiment 2
- Learning Rate: 1e-4
- Epochs: 3
- Training Time: 34.3 minutes
